## Header policy rationale

The modern tools/call path emits five CORS-unsafe fixed names: authorization,
content-type, mcp-method, mcp-name and mcp-protocol-version. Its fixed Accept value
is safelisted; it has no legacy session header. Fetch lowercases and deduplicates
unsafe names, then joins them with commas without spaces. Each validated name
contains only ASCII token bytes, so its string length is its byte length.

The server's 100 limit counts dynamic Mcp-Param-* names only; its 8192 limit
counts the complete Access-Control-Request-Headers string. A 100-binding catalog
with short names is valid even though the total includes five more fixed names.
Both implementations retain these semantics; the server budget is not expanded.

References: [Fetch preflight algorithm](https://fetch.spec.whatwg.org/#cors-preflight-fetch)
and [MCP Streamable HTTP](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http).
